# 徐萱 · 创作档案

个人作品集网站，展示内容产品、品牌视觉、公共空间方案及创作实践。

## 网站内容

- 六个精选项目与双语案例
- 可拖动的作品关系图与流程探索
- 刊物浏览、设计稿与实际应用对照
- 简历及完整作品集下载

## GitHub Pages

将本目录内容放到仓库根目录。在 Settings → Pages 中选择 Deploy from a branch，分支为 main，目录为 / (root)，保存后等待发布完成。

`index.html`、两个 JavaScript 文件、`style.css`及全部图片、字体和文档文件 需要一起保留。
